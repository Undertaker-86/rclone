Privacy policy

Last updated: 11 October 2026

Purpose and access

This personal rclone setup accesses my own Google Drive files and metadata to browse, download, upload, edit, and delete files on my behalf.

Storage

Authentication credentials and tokens are stored locally on my computer. Downloaded file data may also be cached locally. Files uploaded to Drive are stored by Google.

Sharing

This setup does not sell Google account data or intentionally share it with third parties. It communicates with Google to perform the file operations I request.

Public website

This website contains only information about the setup. It does not receive my Drive files or authentication tokens. GitHub Pages hosts these pages and logs visitor IP addresses for security purposes.

Removing access

I can revoke access through my Google Account connections settings and remove local credentials and cached files.
